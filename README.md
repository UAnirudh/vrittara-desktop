# Vrittara desktop

Windows preview downloads for Vrittara. Your existing Vrittara account is required.

Download the ZIP for your PC from [Releases](https://github.com/UAnirudh/vrittara-desktop/releases). Extract the entire ZIP and open Vrittara.exe. Ctrl + Shift + Space opens the launcher.

- Windows: Intel or AMD PCs (x64).
- Windows on ARM: Snapdragon PCs (ARM64).

These previews are unsigned. Windows may show a security warning. Updates are downloaded manually. macOS and Linux downloads are not available yet.

This repository hosts distributable previews and their checksums. Product development is maintained separately.
